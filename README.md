# Shruti Makwana, Portfolio

React + Vite portfolio site. Soft blush / lavender theme, fully responsive.

## Run it
```bash
npm install
npm run dev        # open the local link it prints
```

## Build for hosting
```bash
npm run build      # creates the dist/ folder
```
Upload `dist/` to Vercel, Netlify or GitHub Pages (works from any path).
Easiest: push this folder to GitHub and import it in Vercel (framework: Vite).

## Edit your content
Everything (about text, projects, skills, links) is in `src/data.js`.
Colours are at the top of `src/styles.css` (`:root`).
Replace `public/resume.pdf` to update the resume download.
